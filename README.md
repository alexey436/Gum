# 3:16 GYM — Офіційний веб-сайт мережі спортивних клубів

Сучасний, адаптивний веб-сайт преміум-класу для мережі спортивних клубів **3:16 GYM** (філіали у **м. Сміла** та **м. Золотоноша**).

Розроблено за принципами Dark Athletic Luxury, Mobile-First ергономіки та бездоганної швидкодії (60 FPS, нативний плавний скрол, нуль затримок).

---

## ⚡ Основні можливості

- **Мультифіліальність (Сміла / Золотоноша)**:
  - Модальне вікно вибору філіалу при першому вході зі збереженням вибору в `localStorage`.
  - Динамічна зміна контактів, адрес, графіків роботи, Instagram-посилань, фотографій інтер'єру, тренерського складу та тарифів залежно від обраного міста.
- **Бронювання тренування (0 грн)**:
  - Інтерактивна форма запису на безкоштовне перше заняття або персональне тренування.
  - Автоматичне підставлення обраного тренера чи тарифу в заявку.
  - Захист від помилок та миттєве підтвердження з анімацією успіху.
- **Каталог тренерів**:
  - Картки наставників з кваліфікаціями, спеціалізацією, досягненнями та швидким записом на тренування.
- **Зони клубу та фотогалерея**:
  - Кардіо, вільні ваги (до 50 кг), кросфіт-зона та фітнес-бар.
  - Повноекранний перегляд фотографій з високою роздільною здатністю та резервними заставками (`ImageWithFallback`).
- **Мобільна оптимізація**:
  - Нижній ергономічний Quick Bar для швидких дій однією рукою на смартфоні (виклик, навігація, запис).
  - Адаптивне меню-шторка для планшетів та смартфонів.
  - Приховане бургер-меню на ПК для чистого десктопного інтерфейсу.

## 🚀 Швидкий старт для локальної розробки

### 1. Клонування репозиторію

```bash
git clone https://github.com/ВАШ_ЛОГІН/316gym.git
cd 316gym
```

### 2. Встановлення залежностей

```bash
npm install
```

### 3. Запуск сервера розробки

```bash
npm run dev
```

Відкрийте в браузері [http://localhost:3000](http://localhost:3000).

### 4. Збірка для продакшену

```bash
npm run build
```

Зібрані статичні файли будуть створені в папці `dist/`.

Для попереднього перегляду зібраного проекту:

```bash
npm run preview
```

### 5. Перевірка типів та лінтинг

```bash
npm run lint
```

## 🤖 GitHub Actions & Автоматичний деплой (CI/CD)

У проєкт додано готовий workflow: `.github/workflows/deploy.yml`.

### Що робить цей workflow:
1. **Автоматична перевірка**: при кожному `push` або `pull_request` запускається перевірка типів TypeScript (`npm run lint`) та компіляція проєкту (`npm run build`).
2. **Автодеплой на GitHub Pages**: при оновленні гілки `main` або ручному запуску сайт автоматично публікується на безкоштовному хостингу GitHub Pages.
3. **Ручний запуск (workflow_dispatch)**: ви можете в будь-який момент перезапустити збірку або деплой через вкладку **Actions** на GitHub, натиснувши кнопку **«Run workflow»**.

### Як увімкнути GitHub Pages у репозиторії:
1. Перейдіть у ваш репозиторій на GitHub → **Settings** → **Pages** (у лівому меню).
2. У розділі **Build and deployment** під пунктом **Source** оберіть:
   - **GitHub Actions**.
3. Після цього кожен `push` або запуск через вкладку Actions автоматично збиратиме та публікуватиме сайт на вашу адресу вигляду `https://ВАШ_ЛОГІН.github.io/316gym-website/`.
